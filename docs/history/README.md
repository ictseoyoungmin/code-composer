# Historical development evidence

This directory preserves development-slice and release evidence that used to live at repository root.

It is intentionally **not** the user-facing documentation entry point.

- `slices/` — slice reports, release manifests, source/clean-install/package evidence.
- `checksums/` — historical release SHA-256 lists.
- `status/` — historical version/design status snapshots.

Current user documentation starts at the repository `README.md`. Current maintainer navigation starts at `docs/INDEX.md`.
