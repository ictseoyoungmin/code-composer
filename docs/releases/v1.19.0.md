# Code Composer v1.19.0

v1.19.0 adds the production-closed **steel-string acoustic-guitar performance system** to the Composer-first Code Composer architecture.

## Added

### Deterministic acoustic-guitar performance system

The v1.19 line develops the guitar as one persistent modeled instrument rather than a collection of disconnected note samples or technique presets.

- steel-string single-string source / bridge-force / body-radiation foundation;
- explicit six-string, fret and physical-position authority;
- right-hand finger, thumb, nail and pick excitation mechanics;
- left-hand damping, dead-note, slide, hammer-on, pull-off and natural-harmonic mechanics;
- coordinated fingerstyle and picked-arpeggio gestures;
- continuous down/up strum traversal with non-uniform correlated per-string force, accents, skipped strings and explicit mute/dead-note states;
- same-guitar body/contact actions including body tap, top slap, bridge hit, string slap, muted/dead strum and nail click;
- persistent six-string state, same-string continuity, shared bridge/body memory, bounded sympathetic coupling and technique-transition continuity;
- passive-energy/stability validation for long-horizon deterministic rendering.

The accepted integrated preset is:

`acoustic_guitar.steel_stateful_performance@1.0.0`

This is a reduced-order, physically informed deterministic synthesis system. It is **not** a full geometry/material-derived FEM/BEM reconstruction of a named physical guitar and does not claim measured instrument replication.

## Reproducibility and authority

The Composer-first authority model remains unchanged:

`User intent → Song → Execution Plan → Performance Score → instrument/performance realization → resolved IR → render/export`

Guitar mechanics preserve authored musical pitch/timing/position/technique authority and derive only the deterministic physical realization permitted by the relevant contracts. Automatic aesthetic scoring is not a closure authority; musical dogfoods were closed by human listening after hard integrity gates.
