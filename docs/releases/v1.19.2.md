# Code Composer v1.19.2

[#85](https://github.com/ictseoyoungmin/code-composer/pull/85) fixes piano decay and adds the optional Balanced concert grand preset.

- Preserve each string’s natural decay when applying the damper and invalidate cached previews from the previous renderer.
- Select `piano.concert_grand_balanced@1.0.0` for a less persistent high-register ring without changing the default Natural preset. Existing scores can keep their current preset.

The release includes the Python wheel, standalone Skill, and Codex and Claude plugin bundles.
