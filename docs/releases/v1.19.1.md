# Code Composer v1.19.1

This patch improves steel-string acoustic guitar legato without requiring changes to existing scores.

- [#82](https://github.com/ictseoyoungmin/code-composer/pull/82): resolve slide, hammer-on, and pull-off sources on the same physical string, even when notes on other strings intervene.
- [#83](https://github.com/ictseoyoungmin/code-composer/pull/83): shorten the old pitch after hammer-on or pull-off contact. Support weak hammer-on sustain without boosting the initial fret attack, changing authored velocity, or increasing the master level.

The existing preset IDs and score schema are unchanged. Releases include the Python wheel, standalone Skill, and Codex and Claude plugin bundles.
