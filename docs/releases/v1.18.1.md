# Code Composer v1.18.1

v1.18.1 is a focused reproducibility patch on top of the v1.18.0 Composer-first release.

## Fixed

### Runner-sensitive drum byte nondeterminism

Issue #2 is closed.

The affected drum paths were deterministic in musical intent but raw float64 SHA-256 values could differ across GitHub-hosted CPU/NumPy dispatch paths. The investigation isolated this to FMA-sensitive last-bit floating-point differences:

- same pinned NumPy 2.2.6 / SciPy 1.15.3;
- Python 3.10 and 3.12 become bit-identical on the same CPU/dispatch path;
- disabling NumPy FMA3 changes the historical raw hash family;
- measured native/FMA-disabled maximum sample delta: `2.78e-16` full scale.

The fix canonicalizes the final post-pan percussion-event output to an exact Q40 grid:

- step: `2^-40 ≈ 9.09e-13` full scale;
- maximum sample movement: `2^-41 ≈ 4.55e-13` full scale;
- approximately `-246.8 dBFS` maximum representation movement;
- synthesis, seed, timing, pitch, envelopes, filters, pan and musical parameters are unchanged before this boundary.
