# S5 — Bowed-String Sound Hardening — CLOSED

Date: 2026-09-17  
Engine version: 1.17.0

## Closure

S5 adds a second bowed-string rendering backend, `bowed_waveguide`, while preserving the existing `bowed_string` synthetic/additive engine and `bowed.violin.synthetic_warm` preset unchanged.

The new factory preset `bowed.violin.modeled_open@1.0.0` materializes a physically-inspired two-segment digital waveguide. Bow position divides bridge-side and finger/nut-side propagation segments. Relative bow/string velocity drives a bounded nonlinear friction/scattering junction. String loss occurs in the feedback loop. Bridge motion is then filtered by an explicit violin-family body/radiativity bank.

The body preset is not a claim to reproduce a named instrument. Its broad landmarks are informed by published violin acoustics: A0 around 280 Hz, B1-region corpus modes around roughly 430–580 Hz, and higher radiativity/bridge regions around 2.4 and 3.5 kHz.

## Narrow bottleneck

S5 closes sustained-bow causal synthesis, not the whole violin sound problem.

A modeled A4 long bow:

- remains stable after attack instead of decaying like a struck keyboard sound;
- is generated by a feedback string loop rather than additive harmonic oscillators;
- responds materially to bow pressure, bow speed and bow position;
- tracks target pitch within the S5 tolerance;
- is deterministic across repeated renders and clean installation.

The validation bundle contains a synthetic-vs-modeled A/B file and a G3/D4/A4/E5 modeled register sweep. These are repository validation artifacts and are not shipped in the agent Skill.

## Research provenance

Architecture was informed by, but independently implemented from, public physical-modeling references including Julius O. Smith's bowed-string digital-waveguide descriptions, Faust `physmodels.lib`, STK `Bowed`, published violin radiativity/body-mode work, and finite-width bowed-string excitation literature. No third-party source code was vendored into Code Composer.

## Explicitly still open

S5 does **not** yet close:

- continuous waveguide state across separate note events;
- physically explicit bow-direction-change transients;
- finite-width bow contact;
- torsional string modes;
- measured body impulse-response convolution;
- harmonics/pizzicato/spiccato/ricochet sound models.

The next sound-hardening slice should therefore target continuous note-to-note/bow-change state before adding more special techniques.
