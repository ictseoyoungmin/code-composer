# S5 — Bowed-String Sound Hardening

S5 addresses the sound-generation axis, not violin fingering/playability. S3/S4 remain the physical-performance planner; S5 adds a second bowed synthesis backend that consumes the same explicit bow controls.

## Research basis

The selected architecture follows established bowed-string physical modeling:

1. A bowed string is represented as traveling waves with a nonlinear friction interaction at the bow contact point. The relative bow/string velocity moves between stick-like and slip-like regimes rather than merely scaling an oscillator envelope.
2. Bow position divides the propagation path into a bridge-side and finger/nut-side segment.
3. String losses are applied in the feedback loop.
4. The bridge velocity excites a separate body/radiativity model. The bundled modeled violin body uses broad violin-family landmarks rather than claiming to reproduce a named physical instrument: A0 around 280 Hz, B1-region modes around 430–580 Hz, plus higher radiativity/bridge regions around 2.4 and 3.5 kHz.
5. Vibrato modulates pitch and also couples subtly to amplitude; it is not treated as a timbre preset or melodic rule.

Useful public references used for the architecture:

- Julius O. Smith, *Physical Audio Signal Processing*, Bowed Strings / Bow-String Scattering Junction.
- Faust `physmodels.lib`: waveguides, `violinBow`, `violinBowedString`, `violinBridge`, `violinBody`, `violinModel`.
- STK `Bowed`: two propagation delays, nonlinear bow interaction, string loss and body filtering.
- Bissinger (2008), violin radiativity profile: A0, B1, bridge-hill and bridge-filter regions.
- Holm & Toiviainen (2004), finite-width excitation for DWG bowed strings, as a future hardening direction beyond S5.

## Engine boundary

S5 does **not** mutate the existing `bowed_string` implementation or its `bowed.violin.synthetic_warm` factory preset.

New path:

`bowed.violin.modeled_open` → `bowed_waveguide` engine → two-segment fractional-delay waveguide → nonlinear bow junction → explicit body modal/radiativity filter.

This keeps historical renders stable while allowing modeled sound work to proceed independently.

## Narrow closure target

S5 closes the first sound bottleneck only:

> A single 3–5 second sustained bow should be generated by a causal feedback string model and remain stable after attack, instead of sounding like an oscillator/electric-piano sustain with violin-flavored filtering.

The slice does not yet claim continuous state across separate note events. Full note-to-note legato, explicit bow-change transients, finite-width bow contact, torsional waves and measured body impulse responses remain future sound-model work.
