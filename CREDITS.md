# Credits, Research Acknowledgements, and Provenance

Code Composer is independently implemented. This file records external research, software, and data resources that materially informed its design, especially the bowed-string/violin work in S3-S13, the acoustic-piano release hardening in S14, ensemble-interaction work in S15, plucked-bass acoustic-fidelity work in S16, and percussion acoustic-fidelity work in S17.

This document is an acknowledgement/provenance record, not a substitute for third-party license texts. If Code Composer later bundles third-party source code, measurement assets, impulse responses, recordings, models, or other redistributable artifacts, their exact license and attribution requirements must also be carried in an asset-local notice or `THIRD_PARTY_NOTICES.md`.

## Current distribution status

As of v1.17.0 S17:

- no third-party source code is vendored into the Code Composer runtime;
- no third-party measured violin impulse response, bridge-admittance response, audio recording, or named-instrument dataset is bundled in the installable Skill;
- bowed-string and admittance implementations are independent Code Composer implementations informed by the references below;
- validation audio generated by Code Composer is project-generated evidence, not copied reference audio;
- S9 ships a measurement-ingestion/ERA-fitting path, but does not ship a factory preset claiming to reproduce a measured named violin.

## Software and implementation references

### Julius O. Smith — Physical Audio Signal Processing

Julius O. Smith's public physical-modeling material on digital waveguides and bowed strings informed the high-level decomposition used in S5 and later slices: traveling-wave string state, a nonlinear bow/string interaction, losses in the feedback loop, and a separate body/radiation stage.

- Author: Julius O. Smith III
- Resource: *Physical Audio Signal Processing*
- Relevant topic: bowed strings / bow-string scattering junction / digital waveguides
- Project usage: conceptual and algorithmic reference only; no source code copied.
- URL: https://ccrma.stanford.edu/~jos/pasp/

### STK — The Synthesis ToolKit

STK's `Bowed` instrument was consulted as a public reference for a practical real-time bowed-string digital-waveguide architecture using propagation delays, nonlinear bow interaction, string loss, and body filtering.

- Project: The Synthesis ToolKit in C++ (STK)
- Original authors/maintainers: Perry R. Cook, Gary P. Scavone, and contributors
- Project usage: architecture/reference comparison only; Code Composer does not vendor STK code.
- STK's published license is permissive and requires retaining its notice when redistributing STK software; no STK software is redistributed here.
- URL: https://ccrma.stanford.edu/software/stk/

### Faust Physical Modeling Libraries

Faust physical-modeling resources were consulted for the decomposition of violin bow, bowed string, bridge, and body components and for comparison with established digital-waveguide practice.

- Project: Faust / Faust Libraries, GRAME-CNCM
- Relevant library: `physmodels.lib`
- Project usage: conceptual/reference comparison only; Code Composer does not vendor or compile Faust library source.
- Licensing note: licensing in the wider Faust Libraries varies by file/contributor, and an open upstream issue has specifically requested an explicit license declaration for `physmodels.lib`. Code Composer therefore treats this resource strictly as a reference unless a future integration audits the exact upstream file/version and license.
- URL: https://faustlibraries.grame.fr/libs/physmodels/
- Repository: https://github.com/grame-cncm/faustlibraries

## Research publications

The following publications materially informed the violin-performance or physical-model architecture. Citation here acknowledges research influence; publication content is not redistributed by Code Composer.

### Bowed-string excitation and violin body/radiation

1. George Bissinger, **"Structural acoustics model of the violin radiativity profile,"** *Journal of the Acoustical Society of America*, 124(6), 4013-4023, 2008. DOI: `10.1121/1.3006957`.
   - Informed the broad violin-family A0/B1/bridge-region landmarks used before measured-response fitting was introduced.

2. Jan-Markus Holm and Petri Toiviainen, **"A Method for Modeling Finite Width Excitation in Physical Modeling Sound Synthesis of Bowed Strings,"** *Journal of New Music Research*, 33(4), 345-354, 2004. DOI: `10.1080/0929821052000343822`.
   - Informed future-facing consideration of finite-width bow excitation beyond a point-contact approximation.

3. Mark Sterling and Mark F. Bocko, **"Empirical physical modeling for bowed string instruments,"** *ICASSP 2010*, 433-436. DOI: `10.1109/ICASSP.2010.5495754`.
   - Informed the separation of bowed-string dynamics, measured bridge mechanical admittance, and radiativity.

4. Romain Michon, Julius O. Smith, Matthew Wright, Chris Chafe, John Granzow, and Ge Wang, **"Mobile Music, Sensors, Physical Modeling, and Digital Fabrication: Articulating the Augmented Mobile Instrument,"** *Applied Sciences*, 7(12):1311, 2017. DOI: `10.3390/app7121311`.
   - Informed comparison with Faust-based physical-model composition and modular virtual instrument parts.

5. Esteban Maestre, Gary P. Scavone, and Julius O. Smith, **"Joint Modeling of Bridge Admittance and Body Radiativity for Efficient Synthesis of String Instrument Sound by Digital Waveguides,"** *IEEE/ACM Transactions on Audio, Speech, and Language Processing*, 2017. DOI: `10.1109/TASLP.2017.2689241`.
   - Directly informed the S8 separation of bridge-admittance loading from radiated body output.

6. Francesco Sorge, **"Vibratory Coupling Between Strings and Soundbox in Bowed Instruments,"** *Journal of Vibration Engineering & Technologies*, 2023. DOI: `10.1007/s42417-023-00994-6`.
   - Informed the S7 multi-string/soundbox coupling model and the decision to retain multiple physical-string states.

### Bow control, transitions, and performance realization

7. Esteban Maestre, Merlijn Blaauw, Jordi Bonada, Enric Guaus, and Alfonso Pérez, **"Statistical Modeling of Bowing Control Applied to Violin Sound Synthesis,"** *IEEE Transactions on Audio, Speech, and Language Processing*, 18(4), 855-871, 2010. DOI: `10.1109/TASL.2010.2040783`.
   - Informed the use of time-varying bow velocity, force, and bow-bridge/contact-position controls rather than treating violin expression as note velocity alone.

8. Erwin Schoonderwaldt, Matthias Demoucron, Eckart Altenmüller, and Marc Leman, **"Auditory perception of note transitions in simulated complex bowing patterns,"** *Journal of the Acoustical Society of America*, 133(6), 4311-4320, 2013. DOI: `10.1121/1.4802635`.
   - Informed bow-change/string-crossing transition modeling and the treatment of transitions as coordinated gestures.

9. Erwin Schoonderwaldt and Eckart Altenmüller, **"Coordination in Fast Repetitive Violin-Bowing Patterns,"** *PLOS ONE*, 9(9):e106615, 2014. DOI: `10.1371/journal.pone.0106615`.
   - Informed S6/S7 timing and coordination assumptions for bow reversal and string crossing.

### Measured bridge-admittance fitting

10. Riccardo Giampiccolo, Alessandro Ilic Mezza, Raffaele Malvermi, Mirco Pezzoli, Alberto Bernardini, and Fabio Antonacci, **"Eigensystem Realization of Violin Bridge Admittances,"** *Proceedings of the International Conference on Digital Audio Effects (DAFx-26)*, Cambridge, 2026.
    - Informed S9's use of the Eigensystem Realization Algorithm (ERA) to derive compact state-space models from measured bridge-admittance impulse responses.
    - Archive: https://www.dafx.de/paper-archive/details/hifqirtku4aWV5YCHlYDnw


### Performance-to-timbre expression hardening

11. Erwin Schoonderwaldt, **"The Violinist’s Sound Palette: Spectral Centroid, Pitch Flattening and Anomalous Low Frequencies,"** *Acta Acustica united with Acustica*, 95(5), 901-914, 2009. DOI: `10.3813/AAA.918221`.
    - Informed S10's decision to drive timbral drift from bounded bow force/pressure, bow speed and bow-bridge/contact-position trajectories rather than arbitrary EQ randomness.

12. Maureen Mellody and Gregory H. Wakefield, **"The time-frequency characteristics of violin vibrato: Modal distribution analysis and synthesis,"** *Journal of the Acoustical Society of America*, 107(1), 598-611, 2000. DOI: `10.1121/1.428326`.
    - Informed S10's coupling of vibrato to partial/amplitude energy rather than treating vibrato as pitch modulation alone.

13. Knut Guettler, **"On the Creation of the Helmholtz Motion in Bowed Strings,"** *Acta Acustica united with Acustica*, 88(6), 970-985, 2002.
    - Informed conservative finite attack/reversal control changes through bow force/acceleration-related onset behavior.

These publications are research references only. S10 independently implements its deterministic control layer and does not copy or redistribute publication code, audio, measurements, figures, or data.


### Phrase-scale expressive performance modeling

14. W. F. Thompson, Johan Sundberg, Anders Friberg, and Lars Frydén, **"Rules for Expression in the Performance of Melodies,"** *Psychology of Music*, 17(1), 63-82, 1989. DOI: `10.1177/0305735689171006`.
    - Informed S11's explicit phrase-arch approach: expressive performance is represented as structured control over intensity/timing/duration rather than as unconstrained random humanization.

15. Anders Friberg, Roberto Bresin, and Johan Sundberg, **"Overview of the KTH rule system for musical performance,"** *Advances in Cognitive Psychology*, 2(2-3), 145-161. DOI: `10.2478/v10053-008-0052-x`.
    - Informed S11's separation between authored phrase/grouping intent and deterministic realization of performance variables.

S11 independently maps its phrase envelopes onto Code Composer's existing normalized bow/vibrato controls. It does not copy rule-system source code, score data, audio, or publication assets.



### Ensemble timing, leadership, and interpersonal coordination

23. Werner Goebl and Caroline Palmer, **"Synchronization of Timing and Motion Among Performing Musicians,"** *Music Perception*, 26(5), 427-438, 2009. DOI: `10.1525/mp.2009.26.5.427`.
    - Informed S15's use of explicit musical-role timing relationships and the decision not to equate realistic ensemble performance with sample-exact simultaneous onset.

24. Renee Timmers, Satoshi Endo, Amanda Bradbury, and Alan M. Wing, **"Synchronization and leadership in string quartet performance: a case study of auditory and visual cues,"** *Frontiers in Psychology*, 5:645, 2014. DOI: `10.3389/fpsyg.2014.00645`.
    - Informed the view that ensemble leadership can be section/context dependent and that real coordination is more differentiated than one permanent global leader/follower hierarchy.

S15 independently implements authored bounded timing offsets, overlap-weighted support yielding, and role pan offsets. No publication code, performance data, score data, motion capture, or recordings are copied or redistributed.

### Acoustic piano release, damping, and soundboard behavior

20. Haifan Xie, **"Physical Modeling of Piano Sound,"** arXiv:2409.03481, 2024.
    - Informed S14's system-level view of dampers, strings, bridge/soundboard coupling, and the requirement that damper state constrain post-note vibration rather than leaving independent oscillator tails.

21. Kerem Ege, Xavier Boutillon, and Marc Rébillat, **"Vibroacoustics of the piano soundboard: (Non)linearity and modal properties in the low- and mid-frequency ranges,"** arXiv:1212.2323 / *Journal of Sound and Vibration*, 2013.
    - Informed the treatment of soundboard modes as a damped body response rather than independent musical oscillators that should remain foreground after the strings are damped.

22. Isao Nakamura, **"Fundamental theory and computer simulation of the decay characteristics of piano sound,"** *Acoustical Science and Technology* 10(5), 289-297, 1989. DOI: `10.1250/ast.10.289`.
    - Informed S14's distinction between coupled-string double-decay behavior and mistuning-driven beating, motivating release-only damping of secondary detuned strings instead of removing unison detuning during attack/sustain.

S14 is an independent implementation. No publication code, measured piano data, impulse response, or recording is bundled or copied.

### Violin physical-technique realism hardening

16. Erwin Schoonderwaldt and Matthias Demoucron, **"An extended geometric model for analysis of string crossings in bowed-string instrument performance,"** 2012 conference publication.
    - Informed S12's treatment of string crossing as a finite bow-force/contact transfer whose geometry changes when strings are stopped, rather than as an instantaneous symbolic string switch.

17. Erwin Schoonderwaldt, Matthias Demoucron, Eckart Altenmüller, and Marc Leman, **"Acoustical features of complex bowing patterns in violin performance,"** 2013 conference publication.
    - Informed S12's conservative ordering of string-crossing contact transfer relative to bow reversal and attack stabilization.

18. Erwin Schoonderwaldt, Matthias Demoucron, Eckart Altenmüller, and Marc Leman, **"Auditory perception of note transitions in simulated complex bowing patterns,"** *Journal of the Acoustical Society of America*, 133(6), 4311-4320, 2013. DOI: `10.1121/1.4802635`.
    - Informed the use of finite transition windows for coordinated bow/string changes and perceptually plausible attack boundaries.

S12 independently implements technique-aware control and damping from existing Code Composer realization state. It does not copy or redistribute publication code, figures, measurements, audio, or datasets.

### S13 articulation expansion

19. Matti Karjalainen, Vesa Välimäki, and Tero Tolonen, **"Plucked-string models: From the Karplus-Strong algorithm to digital waveguides and beyond,"** *Computer Music Journal*, 22(3), 17-32, 1998. DOI: `10.2307/3681155`.
    - Informed S13's separation of a pluck excitation from subsequent free string decay and its use of pluck position to shape partial weighting.

20. Knut Guettler and Anders Askenfelt, **"On the Kinetics of Spiccato Bowing,"** *Proceedings of the Institute of Acoustics*, Vol. 19, Part 5, 1997.
    - Informed S13's finite bow-contact window followed by an off-string/free-decay phase for detached spiccato notes.

21. Charlotte Desvages and Stefan Bilbao, **"Two-Polarisation Physical Model of Bowed Strings with Nonlinear Contact and Friction Forces, and Application to Gesture-Based Sound Synthesis,"** *Applied Sciences*, 6(5):135, 2016. DOI: `10.3390/app6050135`.
    - Informed S13's treatment of harmonics as light finger/string contact and bouncing-bow gestures as physical interaction states rather than post-EQ labels.

S13 independently implements deterministic articulation realization inside Code Composer. It does not copy or redistribute publication code, figures, audio, measurements, or datasets. Canonical MIDI remains the authored sounding pitch for harmonic events.

### S16 plucked-bass acoustic fidelity

25. Zulfadhli Mohamad, Simon Dixon, and Christopher A. Harte, **"Pickup position and plucking point estimation on an electric guitar,"** *ICASSP 2017*. DOI: `10.1109/ICASSP.2017.7952236`.
    - Informed the S16 use of pluck-position and pickup-position spatial terms to shape harmonic amplitude and spectral nulls in an ideal-string-style model.

26. Oleksii Vodka, Mariia Shapovalova, Vitalii Ovcharenko, and Olena Avdieieva, **"Modeling Bass Guitar String Vibration with Frequency- and Fret-Dependent Damping for Real-Time Sound Generation,"** *Vibration*, 9(3):46, 2026. DOI: `10.3390/vibration9030046`.
    - Informed S16's decision to make partial decay frequency dependent rather than sustaining a fixed oscillator mixture throughout a bass note.

S16 independently implements a compact generic fingerstyle bass model. It does not copy or redistribute publication source code, measured bass recordings, damping tables, pickup measurements, datasets, or instrument-specific fitted values.


### S17 percussion acoustic fidelity

27. Federico Avanzini and Riccardo Marogna, **"A Modular Physically Based Approach to the Sound Synthesis of Membrane Percussion Instruments,"** *IEEE Transactions on Audio, Speech, and Language Processing*, 18(4), 891-902, 2010. DOI: `10.1109/TASL.2009.2036903`.
    - Informed S17's compact decomposition of struck membrane percussion into impact excitation, modal membrane response, amplitude-dependent/tension-relaxation pitch behavior, and separately damped resonant components.

28. Michele Ducceschi, Matthew Hamilton, and Riccardo Russo, **"Simulation of the Snare-Membrane Collision in Modal Form Using the Scalar Auxiliary Variable (SAV) Method,"** *Forum Acusticum 2023*. DOI: `10.61782/fa.2023.0995`.
    - Informed S17's treatment of snare wires as repeated collision/rattle energy coupled to a membrane/body response rather than as one stationary noise burst.

S17 independently implements a compact deterministic acoustic-kit approximation. It does not copy or redistribute publication code, simulation meshes, recordings, measured modal tables, impulse responses, figures, or fitted instrument data. The shipped modeled kit is generic and does not claim to reproduce a named drum kit, drumhead, cymbal, room, or performer.

### S24 cymbal presence and excitation hardening

29. Michele Ducceschi and Cyril Touzé, **"Modal approach for nonlinear vibrations of damped impacted plates: Application to sound synthesis of gongs and cymbals,"** *Journal of Sound and Vibration*, 344, 313–331, 2015. DOI: `10.1016/j.jsv.2015.01.029`.
    - Informed S24's emphasis on a wide modal field and broadband energy emerging from plate dynamics rather than treating cymbal realism as an independent white-noise tail.

30. Toshiya Samejima, **"Nonlinear physical modeling sound synthesis of cymbals involving dynamics of washers and sticks/mallets,"** *Acoustical Science and Technology*, 42(6), 314–325, 2021. DOI: `10.1250/ast.42.314`.
    - Informed S24's decision to make impact/contact character part of the cymbal excitation/body response rather than a detached post-noise effect.

S24 independently implements a compact deterministic reduced-order approximation. It does not copy or redistribute publication code, meshes, recordings, measured cymbal responses, figures, or fitted instrument data.

## Attribution policy for future measured assets

A future measured-instrument resource may only be bundled after all of the following are recorded:

1. exact source record and persistent identifier (preferably DOI);
2. original authors/creators and institutional attribution;
3. exact file identity and checksum;
4. measurement meaning and units (for example force-normalized bridge velocity);
5. source instrument identifier/anonymization constraints;
6. license and redistribution permission;
7. required citation or acknowledgement text;
8. preprocessing performed by Code Composer before fitting;
9. fitted-profile version and source-data hash;
10. whether the resource may be used commercially, modified, and redistributed.

If those conditions are not satisfied, Code Composer may use the source as a research reference but must not ship the underlying asset or label a factory preset as a measured reproduction of that instrument.
