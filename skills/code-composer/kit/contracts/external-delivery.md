# External Delivery Contract

External delivery contains the approved reference mix, full-song MIDI, per-track MIDI, aligned float stems, exact resolved IR, manifest and delivery notes.

The reference mix is the timbre/mix authority. Stems are collaboration sources and are not guaranteed to sum exactly to a nonlinear/shared-FX master. Unsupported tempo maps, CC lanes, pitch bend or DAW-session semantics must not be invented.
