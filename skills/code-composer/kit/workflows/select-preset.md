# Select a Factory Preset

1. Read `kit/presets/CATALOG.json`; do not inspect runtime preset patch files by default.
2. Translate the user's sonic intent into required capabilities and limitations.
3. Shortlist by engine/family/recommended role and expression capabilities.
4. Choose a preset as a starting sound resource, not as a compositional reference.
5. If necessary, author small song-local `patch_overrides` from the current song's needs.
6. Compile the brief and verify that canonical Music IR contains a fully materialized patch plus exact preset provenance.
7. Render and judge the sound in the actual arrangement. If it does not serve the composition, change/adapt the preset; do not force the composition to fit it.
