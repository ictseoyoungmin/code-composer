# Revise Workflow

1. Preserve the current canonical Music IR and provenance before editing.
2. Identify the narrowest failing musical scope from render + evidence.
3. Check whether the failure is local or caused by an upstream form/harmony/orchestration decision.
4. Let the agent decide the revision from current-song evidence and user intent.
5. Express the change explicitly in structured IR/plan data.
6. Re-render and compare before/after under the same conditions.
7. Keep accepted unaffected scopes stable; reopen them only when evidence shows the premise was wrong.

Do not use bundled fixture note/rhythm values as revision ideas.
