# CR07 — Broader Orchestration Dogfood

This directory contains three independent Composer-first authored examples used to
prove arbitrary track-function preservation across materially different ensembles.

- `copper_lines` — band / rock-like.
- `glass_courtyard` — chamber.
- `blue_relay` — electronic.

The fixtures intentionally use track functions outside a fixed arrangement-role
vocabulary. Unknown instrument families use explicit preset locks. The dogfood does
not introduce a generic fallback or infer roles from names.

CR07 closure requires both engineering evidence and a listening verdict.
